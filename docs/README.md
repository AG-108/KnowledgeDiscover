Local-only working files, ignored by Git and not published: root `STATUS.md` (run state and
backlog; read first), `agent_handoff.md`, `benchmark_results_combined_20261017.md` and
`benchmark_results_tables_20261016.md` (generated by `scripts/build_*`), `benchmark.xmind`,
`paper/` and the repository-level `reports/` (qualification figures and slides).

Sphinx API sources are in `source/`; build with `make html`.
Runtime code is in `kd/`, configurations in `configs/`, examples in `examples/`,
regression tests in `tests/`, reusable commands in `scripts/`, dependency lists in
`requirements/` and server-only activation, image and launch recipes in `server/`.
Git ignores `results/`, `.local/`, `sshkey/`, `checkpoints/`, `external/`, `.env` files
and large external data files such as `kd/dataset/WaveBreaking.pkl`.
